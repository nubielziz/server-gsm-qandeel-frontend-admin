- Tabs (URL `tab`; honour `/settings?tab=tax`, ARCHITECTURE §5.2): **Payment methods** (gateway cards as the demo: enable toggle `st-gw`, fees, limits, merchant groups; create/edit/delete gateways; secrets are write-only), **Tax and currency** (tax rates by country with effective dates: create/edit; currencies with rates, "shown to customers" toggle `st-fx-shown`, edit rate `st-fx-edit`, **Refresh rates** `POST /admin/currencies/refresh-fx` showing the server's result; stale rates highlighted from the DTO's `updatedAt`/stale flag, as the dashboard's fx alert), **Policies** (storefront settings: guest checkout, refund window, payment methods, customer email texts via `PATCH /admin/storefront/settings`; current values from `GET /admin/settings` keys (assumed names, logged)), **Customer emails** (notification templates per event and channel: enable toggle `st-nt`, view/edit, **Preview** via `POST /:id/preview` rendering the server's sample output safely (text, or HTML in a sandboxed `iframe srcdoc` with no scripts)), new **Notification log** (`GET /admin/notifications`: event, channel, recipient as sent by the server (masked), status, time; a row opens details), new **Webhook deliveries** (`GET /admin/webhook-deliveries`: merchant, event, URL, status code, attempts; details drawer with request/response; **Retry** `POST /:id/retry`), new **System** (settings:read/update: the key-value settings this console knows (`imeiRetentionDays`, …) with a typed form; unknown keys shown read-only as JSON).
