## Assumed contracts (log each in MISMATCHES; types in `src/features/customers/types/`, JSDoc "Assumed contract")
- `Customer` = `CustomerRow` fields with `riskLevel: 'low' | 'medium' | 'high'` (demo says `med`), `status: 'active' | 'suspended' | 'blocked' | 'anonymized'`, plus list aggregates `ordersCount: number`, `lastOrderAt: string | null`. `createdBy: number | null` reads as: null + hasAccount → "Signed up on the storefront", null + guest → "Bought as a guest", a staff id → "Added by your team".
- `GET /admin/customers/:id` → `CustomerDetail` = `Customer` & `{ stats: { orders; spent: Money; lastOrderAt; refunds; tickets; disputes }; account: { emailVerified: boolean; mustChangePassword: boolean; passwordChangedAt: string | null; resetSentAt: string | null; activeSessions: number; lastIp: string | null } | null /* null for a guest */; latestConsents: { orderId: number; records: { purpose: string; document: string | null; at: string; ip: string }[] } | null; risk: { highestScore: number | null; signals: { text: string; orderId: number }[] } }`.
- List filters: `q` (name, email), `country`, `status`, `riskLevel` (array allowed: Flagged tab = `['medium','high']`); sortable `name`, `country`, `hasAccount`, `ordersCount`, `totalSpent`, `lastOrderAt`, `riskLevel`, `status`; default sort `totalSpent` desc (demo). Tab counts like orders' `useOrderCounts` (one cheap count query per tab).
- Bodies: create `{ name, email, country, locale, phone?, password: { mode: 'reset_link' | 'temporary_password' } }` → 201 `Customer & { temporaryPassword?: string }` (EMAIL_TAKEN 409 → field error on email); PATCH only changed fields `{ name?, email?, country?, locale?, phone?, internalNotes? }` (no call when nothing changed: toast "Nothing changed"); account `{ mode }` and password `{ mode, revokeSessions }` → `{ temporaryPassword?: string }` shown once (temporary passwords are made by the server, as for staff, MISMATCHES M12; reuse access's reveal-once flow: `RevealPasswordDialog` is exported from `@/features/access`; use `gcTime: 0` on those mutations like access does); suspend `{ reason, note? }`; block `{ blocked: true, reason } | { blocked: false }`; export → JSON file download `customer-<id>.json` via the client's download helper; anonymize → 204; data request PATCH `{ status: 'in_progress' | 'completed' | 'rejected', note? }`. `DataRequest` = `DataRequestRow` with `kind: 'export' | 'erasure'`, `status: 'open' | 'in_progress' | 'completed' | 'rejected'`, plus `customerName`.
