# Commands
- `npm run dev` (add `VITE_API_MOCKS=true` for the MSW mock layer), `npm run build`, `npm run preview`.
- `npm run typecheck`, `npm run lint` (eslint + prettier --check), `npm run format`, `npm test` (vitest run).
- `npm run routes:manifest` (rebuild docs/route-manifest.*), `npm run gen:types` (src/lib/api/schema.gen.ts), `npm run routes:coverage` (docs/ROUTE_COVERAGE.md, Phase 4).
